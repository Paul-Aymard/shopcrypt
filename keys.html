Mes clés RSA

Votre clé publique est un cadenas ouvert : vous la publiez pour que les autres puissent vous écrire. Votre clé privée est la seule clé qui ouvre ce cadenas : elle reste sur votre ordinateur et n’est jamais envoyée au serveur.

État

  • Clé publique publiée sur le serveur : …
  • Clé privée chargée dans cet onglet : …

Générer une nouvelle paire de clés

RSA-OAEP · 2048 bits · SHA-256 · exposant public 65537. La génération se fait entièrement dans votre navigateur.

Attention : vous avez déjà une clé publiée. Si vous publiez une nouvelle clé, les messages déjà reçus ne pourront plus être lus qu’avec l’ANCIEN fichier .pem.

Étape obligatoire avant de publier : téléchargez et rangez votre clé privée.

Charger ma clé privée (.pem)

Nécessaire pour déchiffrer vos messages après une reconnexion ou sur un autre ordinateur. Le fichier est lu localement : il n’est pas envoyé sur Internet.
